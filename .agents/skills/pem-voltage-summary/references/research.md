# PEM 수전해 멀티미터 전압 로깅 분석 기준

## 1. 하드웨어 로깅 사양
- **측정 주기**: 2초당 1회 (2초에 1행)
  - 1분 = 30행
  - 1시간 = 1,800행
- **최대 저장 용량**: 20,000행 (약 11시간 6분 40초 분량)
- **정상 작동 전압 범위**: 통상 1.5V ~ 2.2V

## 2. 결측치 및 이상치 판정 기준
1. **급격한 전압 점프 (이상값)**:
   - 연속된 1시간 주기 측정값 간의 전압 차이가 직전 값 대비 **$0.05\text{ V}$ ($50\text{ mV}$) 이상 급격히 변동**하는 경우 이상값(Spike/Noise/Contact Error)으로 판정한다.
2. **결측값 및 범위 초과**:
   - 전압 데이터 값이 비어 있거나(NaN), 산출된 행 인덱스가 전체 데이터 길이를 초과하는 경우:
     $\rightarrow$ 멀티미터 리셋 시각이나 실험 시작 시각이 잘못 입력되었을 가능성이 높으므로 사용자에게 시간 입력값 재확인을 요청한다.

## 3. 시간 기준 셀 인덱스 산출 공식
실험 시작 시각의 '분(minute)'을 목표 기준 분($M_{\text{target}}$)으로 설정하고, 멀티미터 로깅 리셋 시각($T_{\text{reset}}$)과의 차이를 계산하여 매 1시간 주기 행 인덱스를 추출한다.

1. **기준 분 설정**:
   - 실험 시작 시각의 분 $\rightarrow M_{\text{target}}$ (0 ~ 59)
   - 멀티미터 리셋 시각의 분 $\rightarrow M_{\text{reset}}$ (0 ~ 59)

2. **최초 목표 시점까지 남은 시간 ($\Delta t$, 단위: 분)**:
   - $M_{\text{reset}} \le M_{\text{target}}$ 인 경우:
     $$\Delta t = M_{\text{target}} - M_{\text{reset}}$$
   - $M_{\text{reset}} > M_{\text{target}}$ 인 경우 (다음 시간대로 넘어감):
     $$\Delta t = (60 - M_{\text{reset}}) + M_{\text{target}}$$

3. **행(Row) 인덱스 계산**:
   - **첫 번째 측정 행 인덱스 ($N_0$)**:
     $$N_0 = \Delta t \times 30$$
   - **이후 매 1시간 경과 행 인덱스 ($N_k$, $k = 1, 2, 3, \dots$)**:
     $$N_k = N_0 + (1,800 \times k)$$

*(참고: 인덱스는 0-based 또는 1-based 헤더 유무에 따라 1행 오차가 발생하지 않도록 데이터 첫 행을 기준으로 상대 행 수를 더한다.)*
