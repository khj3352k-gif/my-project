# PEM 야간 전압 데이터 요약 절차

## 1. 필수 입력 정보 점검 (중요 규칙)
- 분석을 시작하기 전, 다음 필수 정보가 모두 주어졌는지 확인한다:
  1. **실험 시작 시각** (예: 14시 20분)
  2. **멀티미터 로깅 시작(리셋) 시각** (예: 21시 45분)
- **규칙: 위 두 시각 중 하나라도 누락되었거나 불분명한 경우, 절대 임의로 추정하거나 기본값을 가정하지 말고 사용자에게 두 시각을 반드시 먼저 질문하여 확인받는다.**

## 2. 시간 기준 및 셀 인덱스 산출
- `references/research.md`의 계산 공식에 따라 인덱스를 도출한다.
  1. 실험 시작 시각의 '분'을 기준 분($M_{\text{target}}$)으로 설정한다.
  2. 리셋 시각($M_{\text{reset}}$)부터 최초 기준 분까지 걸리는 시간($\Delta t$, 분)을 구한다.
  3. 첫 번째 타깃 행($N_0 = \Delta t \times 30$)을 결정한다.
  4. 이후 매 1시간 간격($+1,800$행)마다 인덱스($N_k$)를 산출한다 (최대 20,000행 이내).

## 3. 데이터 추출 및 전압 안정성 분석
- 계산된 각 인덱스($N_k$)의 전압값을 추출한다.
- `references/research.md`의 기준에 따라 결측치 및 이상치를 판정한다:
  - 전압 데이터가 비어있거나 인덱스가 파일 범위를 초과하는 경우: 시간 입력 오류 가능성을 즉시 사용자에게 알린다.
  - 직전 측정 전압 대비 급격한 전압 점프($\ge 0.05\text{ V}$) 발생 여부를 점검한다.
- 최초 측정값 대비 전압 드리프트($\Delta V$, mV) 및 시간당 드리프트율(mV/hr)을 계산한다.

## 4. 출력 보고서 형식
반드시 아래 4가지 항목 순서대로 요약 보고서를 출력한다:
1. **[실험 및 로깅 개요]**: 실험 시작 시각, 로깅 시작 시각, 총 측정 시간 및 행 수
2. **[1시간 주기 전압 추이 표]**: 
   - 컬럼: `경과 시간(hr) | 측정 시각 | 행 번호(Index) | 전압(V) | 이상치 여부`
3. **[안정성 및 이상치 점검]**: 급격한 전압 점프($\ge 0.05\text{ V}$) 발생 구간, 최대/최소 전압, 총 전압 변동량($\Delta V$)
4. **[운전 판정 요약]**: 정상 운전 지속 여부 및 이상 발생 시 권고 조치 사항 (결측 발생 시 시간 입력 재확인 권고)
